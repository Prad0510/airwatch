      How the data flows

      From a 209.5 MB CSV to this dashboard

      1. Raw CSVstation_hour.csv, 2.59M rows
      2. HDFS landing/data/air_quality/raw
      3. Clean and classifyRemove duplicates, turn negatives into nulls, add CPCB classes, join city
      4. ParquetSnappy, partitioned by year and month
      5. QuerySpark SQL, Hive, DuckDB, MapReduce
      6. This dashboardReads dashboard_data.json / Live Backend API

      Design decisions

      What the pipeline does and why

      67year and month partitions. Partitioning by station (110) or by day would create thousands of tiny HDFS files.
      ColumnarParquet reads only the columns a query needs, such as PM2.5 and AQI, instead of all 16.
      3 enginesThe same Parquet table is queried with Spark SQL, Hive external tables and DuckDB.
      MapReduceHadoop Streaming mapper and reducer compute mean, min and max PM2.5 per station.
